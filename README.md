# Workshop GenAI

### 🔗 Link: [https://iebt.github.io/Workshop-GenAI](https://iebt.github.io/Workshop-GenAI)

Workshop sobre Inteligência Artificial Generativa, realizado no IEBT em 2025.

Nesta apresentação, são abordados conceitos de Machine Learning (como Aprendizado Supervisionado/Não Supervisionado/Por Reforço e Redes Neurais) e uma introdução ao funcionamento da IA Generativa.
